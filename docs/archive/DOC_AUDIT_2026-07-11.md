# Documentation Truth Audit — 2026-07-11

> **Method.** 197 subagents. One read every doc / root file / memory file, extracted each *checkable* factual claim, and ruled it against **hard code evidence** (a specific `file:line` in `.gsc`/`.csc`/`.map`/`.gdt`/`.zone`/`.csv`/tooling). Every CONTRADICTED / high-severity finding was independently re-checked by a second, adversarial agent. **Code is the source of truth; where a doc disagrees, the doc is the bug.** Another doc, the CHANGELOG, a memory, or REQUIREMENTS.md never counts as evidence.
> **Scope.** 95 files: 42 docs + 8 root (CLAUDE.md, REQUIREMENTS, MISSING_REQUIREMENTS, ROADMAP, README, ONBOARDING, SETUP, CREDITS) + 45 memory files. CHANGELOG history was excluded by design (its old numbers are intentional).
>
> **✅ STATUS (2026-07-11): ACTIONED.** All 301 code contradictions were reconciled to code truth (269 automated edits + a manual residual pass; **297/305 verified resolved**). Fixing every file to code also collapsed most of the 125 cross-file contradictions. Remaining by choice: the **78 redundant overlaps** (a structural consolidation job — pick a canonical home + add pointers — held for a separate reviewed pass) and 3 cosmetic residuals (stale line-number citations / historical-banner rows). The dev/god flag proved **volatile** (toggled ON/OFF several times a day across parallel sessions), so its docs were rewritten to describe the mechanism and defer to the code rather than assert a state. This report is now a historical record of the audit.
