# Docs index — Abandoned Cyber City

**One doc per topic. This index is the map; each doc below is the _single source
of truth_ for its subject.** Don't scatter the same fact across files — update it
where this index says it lives. Design intent flows top-down: `REQUIREMENTS.md`
(the spec) → these docs → the code. Where a doc and the code disagree, the
**code wins** and the doc is the bug (these were all reconciled against the code
on 2026-07-10).

## Fact ownership — stop cross-doc drift

**The rule:** _code owns every NUMBER; the one doc named below owns each prose topic; every
other doc LINKS instead of restating._ A doc-audit (2026-07-11) found 78 places where the same
fact is duplicated across docs — the pattern that lets one copy go stale. Before you write a
number or a system description into a doc, check this table; if you don't own it, link to the owner.

| Fact class | Canonical owner (source of truth) | Everyone else |
|---|---|---|
| **Any tunable number** (cost, HP, damage, radius, tier, cooldown, weight, %) | the **code** `#define` / `getdvar*` default | describe behavior in prose; **never** restate the literal number — link to the module |
| Boss roster + round cadence | `_acc_civil_protector.gsc` (roster fn) + [08_enemies](08_enemies.md) | docs 03/05/13/32, README, ROADMAP link |
| Boss HP ladder / co-op scaling | [08_enemies](08_enemies.md) prose + `_acc_coop_scaling.gsc` numbers | others link |
| Map anatomy (zone list, door names, mystery-box count) | `CLAUDE.md` code-map | docs 02/11 link |
| Vault / Exo / Foundry / Armory coords | 29 (Exo/Foundry), [37](37_transfer_vault.md) (vault), [39](39_armory.md) (Armory) | docs 02/28/30 defer |
| PaP pricing + box odds | [33_pap_pricing_tiers](33_pap_pricing_tiers.md) + `_acc_pap_levels.gsc` | ROADMAP / REQUIREMENTS defer |
| Overclock model / perk roster + counts | `_acc_overclocks.gsc` / `_acc_perks.gsc` | docs 03/04/10/15 link |
| Weapon arsenal / tiers | [04_weapons](04_weapons.md) | REQUIREMENTS' old roster table is retired |
| Per-gun PaP-form stats | [25_weapon_stats_table](25_weapon_stats_table.md) (generated by `tools/gen_weapon_stats.js`) | never hand-copy a stat |
| Economy sources (shards / bottles / items) | [32_economy_sources](32_economy_sources.md) | others link |
| Boss-item pool + slots | [09_boss_items](09_boss_items.md) + `_acc_boss_items.gsc` | others link |
| HUD internals (LUI models, clientfields) | [19_lui_pipeline](19_lui_pipeline.md) | docs 11 defers |
| Balance/tuning dvars + the hardcoded dev/god flags | [22_flags_reference](22_flags_reference.md) | others link |
| Module count / inventory | one line in [16_community_techniques](16_community_techniques.md) | stop hardcoding a count in prose |
